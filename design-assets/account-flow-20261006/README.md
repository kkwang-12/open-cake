## 总体访问与返回逻辑
| 入口 | 未登录建议 | 登录后／返回行为 |
|---|---|---|
| 我的 | 展示欢迎、默认头像、登录入口、菜单及定制推荐 | 展示头像昵称与真实统计；加载中占位，失败不显示虚假计数 |
| 我的订单／订单导航 | 进入登录，记住来源与原入口 | 成功返回订单；取消回到原页面 |
| 我的收藏 | 进入登录；若仍沿用本机收藏机制可按现有能力开放本机列表 | 成功回收藏；不能未经确认把本机收藏变为云端同步 |
| 收货地址 | 保留本机管理，不强制增加登录门槛 | 列表／编辑／选择与当前本机规则一致 |
| 门店信息／关于品牌 | 直接浏览 | 返回我的或实际来源页面 |
| 生日蛋糕定制 | 按真实商品／定制能力进入选购或详情 | 到需要身份的动作时再按业务规则登录 |
| 客服与帮助 | 可查看公开帮助；联系方式缺失提示准备中 | 接口可用后再开放联系，不做无效跳转 |
| 设置 | 打开现有设置能力；无能力则作为后续入口 | 退出登录需清理会话并回未登录我的，不擅自删除本机地址 |

建议登录携带一次性返回意图（来源、页面、允许恢复的动作），仅允许应用内部已注册页面。成功消费一次，失败保留，取消丢弃；从「我的」主动登录直接返回我的。会话失效转未登录状态，但保留用户尚未提交的必要输入；不得把重新登录当作订单提交成功。

## 01 未登录与已登录我的
未登录保留参考图信息结构：品牌 → 欢迎与默认头像 → 登录按钮 → 三项入口统计 → 生日蛋糕卡 → 六项菜单 → 底部导航。登录提示不遮挡整页；订单与收藏仍可点击，引导去登录。地址显示本机条数或「—」，加载失败可重试。

已登录展示昵称与头像；昵称缺失使用「你好，欢迎回来」，头像缺失使用中性头像。统计以实际数据为准，不能硬编码示例数。只有四个主页面展示底部导航，二级页使用返回键，避免固定操作与导航重叠。

## 02–03 登录界面
两种方案均为建议能力，启用哪一种取决于真实身份服务、微信能力和短信接口；当前提案不代表这些服务已配置。

### 微信快捷登录
1. 进入时协议默认未勾选；用户协议与隐私政策可单独打开，返回保留当前状态。
2. 未勾选点击登录：就地提示「请先阅读并勾选协议」，不发起登录。
3. 已勾选：按钮进入「正在登录…」，防止重复点击。
4. 先通过已接通的微信身份能力完成登录。手机号只在业务确实需要时单独请求，不把昵称头像授权当作登录前提。
5. 用户取消／拒绝：留在登录页，可选择已接入的其他方式；提示「已取消，可继续浏览」。
6. 网络／服务失败：提示「登录失败，请重试」，恢复按钮，不显示成功头像或个人计数。
7. 成功：短提示「登录成功」，返回原入口；首次建账号由服务端确认，不能在接口未确认时宣称已注册。
8. 「暂不登录」或返回键：回来源页，不触发原先受限动作。

### 手机验证码
- 国家／地区默认中国大陆 +86；如上线支持其他地区需另配号码规则，不混用大陆校验。
- 手机号格式有效后可发验证码；后端短信成功受理后开始建议 60 秒倒计时，失败不强制倒计时。
- 短信发送中防重复；倒计时使用真实截止时刻，返回前台不会重置为 60 秒。
- 验证码格式以真实接口要求为准，支持数字输入；填写完整且已勾选协议后才提交。
- 格式错误／过期／次数超限：在验证码下提示真实问题，保留手机号；服务端限流或锁定优先。
- 登录提交中显示忙碌；超时可重试，不能重复创建账号。
- 切换登录方式保留合法手机号与协议状态，不长期保存验证码。
- 未配置短信接口时不显示可执行的验证码入口。

### 返回与协议页面
从协议详情返回保留登录上下文；无前页的直接打开场景回到「我的」。协议页必须使用实际已发布文本，不能使用示意文案代替正式协议。

## 05–08 收货地址
### 列表管理与选择模式
- 管理入口：点击卡片查看／编辑；「编辑」「删除」「设为默认」独立操作，点击区域至少 44px，避免误删。
- 填写订单进入选择模式：标题下提示「请选择本次收货地址」，当前有效选中项显示勾选；点击卡片选定并返回填写订单。
- 设置默认和选择本次地址是不同操作；选定非默认项不自动变成默认项。
- 本机地址允许自然换行。展示页可掩码手机号，编辑页读取完整号码；图中只使用假号码。
- 新增成功回列表显示新项；选择模式不在未经用户选择时自动提交订单。
- 加载失败显示「地址读取失败，请重试」，不能按空列表覆盖原数据。

### 新增／编辑共用表单
新增：空表单、默认开关关闭。编辑：填充原数据、标题改为「编辑收货地址」，保留稳定地址标识。
字段：收货人、手机号码、省市区、详细地址。当前本机表单已有独立省／市／区字段；图中的地区选择器是建议升级，不代表已有区域编码／坐标。
校验：去首尾空白、必要字段齐全、手机号按现有草稿规则校验。错误出现在对应字段下，并定位首个错误。输入与校验失败不丢失草稿。
保存中禁用重复操作；写入成功后才提示「已保存」。存储结果未确认显示「保存结果未确认，请返回列表检查后再操作」。
图中默认开关为建议表单增强：启用后必须保证地址创建／更新已确认，再调用默认设置。若设置默认失败，告知「地址已保存，默认设置失败」，不可冒充全部成功。现有代码只支持列表设置默认，落地时需单独实现这一组合交互。
地址版本变化／被删除：重新读取并提示，不覆盖新记录；保留当前输入供用户确认后重新操作。
返回时未修改直接返回；有未保存修改弹出「放弃本次修改？」与「继续编辑／放弃修改」。键盘打开时滚动保证字段可见，底部固定按钮遵循现有键盘安全区处理。

### 删除与默认地址
- 删除必须确认，弹窗两个操作「保留地址／确认删除」。
- 删除默认地址明确说明「删除后将清空默认地址，不会自动选择其他地址」。
- 删除最后一项进入空状态；不自动创建地址或切换其他项。
- 删除／修改填写订单已选地址：填写订单提示「所选地址已修改或删除，请重新选择」，重新选择并核验。
- 本机地址保存成功不等于配送可用。配送范围、费用、时段、库存仍在订单页按现有规则核验。

### 空、加载与异常状态
空列表：位置线稿图标、「还没有收货地址」、说明、底部新增按钮。
读取中：同尺寸骨架，占位稳定。读取失败：错误与重试；编辑未保存与业务校验不使用全屏加载覆盖。

## 09–10 门店信息
当前项目为单门店，先设计单门店信息 → 门店详情，不额外引入选店、门店切换或多门店库存规则。
展示顺序：门店摄影 → 名称与资料状态 → 地址／营业时间／电话 → 自取配送说明 → 详情入口。
摄影失败使用同尺寸品牌占位。资料读取失败可重试；缺少字段各自显示准备中，不把整页当无门店。
营业时间来自真实配置；「营业中／休息中」须有门店时区与实时状态判断，数据未齐不显示该状态。没有用户定位不显示距离。
门店详情可复用同一份门店资料，地址、时段、电话不能使用两份不一致的数据。

### 导航与电话
- 查看门店信息无需登录或定位权限。
- 门店有有效坐标时「到店导航」可用，调用真实地图能力；缺少坐标显示「地址与坐标待配置」，禁用导航。
- 不请求定位权限只为展示品牌或静态门店。若特定地图操作确实需要权限，在用户触发时解释用途，拒绝仍能阅读地址。
- 导航取消保持详情页；调用失败提示「导航暂不可用」，如地址已确认可提供复制地址。
- 有真实电话才启用拨号；点击联系门店交给系统确认拨号，取消不显示错误。电话未配置显示「正在准备中」与灰色按钮。
- 地图图板明确标注「地图示意 · 非真实定位」，不可直接作为产品地图资源。

### 履约说明
实际项目参考数据是到店自取与门店自行配送、配送半径 20km（含边界）、配送费 0 元、每天 08:00–21:00，且购买仍待云端核验。图板用占位说明保持品牌示例独立；落地应复用当前统一门店服务数据，不把 0 元改成任意运费或自行扩大配送半径。营业时间也不等于所有预约时段都有容量。

## 11 关于品牌
公开可读：LUNE 字标 → 品牌摄影 → 品牌理念 → 三项坚持 → 用户协议／隐私政策。品牌故事为示例文案，发布前由用户确认；不虚构获奖、产地、历史、资质或健康功效。
长文自然滚动，底部保留安全区。品牌照片失败不改变布局。协议链接打开正文页，返回保持品牌页滚动位置。不存在已发布协议时只显示准备中状态，不跳空链接。
不新增与品牌阅读无关的结算按钮或强制登录浮层。

## 登录后空状态与通用异常补充
- 无订单：「还没有订单」＋「去选购」；有数据读取失败则提示重试，不能显示为零订单。
- 无收藏：「还没有收藏」＋「去发现喜欢的蛋糕」；保持既有本机／云端数据边界。
- 断网：当前页保留已可用的公开信息；个人请求提示重试，不制造登录成功。
- 页面直接打开没有返回栈时：二级页返回「我的」；登录完成按已验证的内部来源跳转。
- 重复点击与异步回调：忙碌时阻止重复写入；用户离页后不弹过期成功提示、不改变新页面。
- 内容多时正常滚动，固定按钮／导航仅计一次安全区；大字体、窄屏和长地址不得遮挡最后一项。

## 逻辑审阅清单
1. 未登录个人入口引导登录，公开页面和本机地址正常访问。
2. 登录成功回来源，取消不执行原动作；未配置登录服务不提供假登录。
3. 地址管理与选择模式区分；设默认不会偷偷改本次订单地址。
4. 删除默认不自动选其他地址；删除已选地址要求订单重选核验。
5. 门店没有电话／坐标时禁用相关操作；无定位不显示假距离。
6. 默认开关、地区选择器、独立门店／品牌页都是建议增强，未误报成当前实现。
7. 暖白灰阶、细线图标、字体职责、主胶囊和返回键与基线对齐。
8. 三张图、提示词与本文一起交付，所有数值和资料示例均可追溯。
