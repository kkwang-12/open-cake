## 本次 UI 变化

| 区域 | 当前实现与交互 |
|---|---|
| 首页 / Hero | 首屏改为场景摄影与中文文案，加入草莓、巧克力、柠檬三张 Hero 图片；原生横向手动轮播、圆点指示，不自动播放或循环。每张图有独立文案及「去选购」入口；滑动、纵向滚动和取消触摸后抑制误触，图片加载 / 失败分别处理。 |
| 首页推荐 | 「今日推荐」与「查看全部」并排；首屏展示两张推荐卡，其余商品继续在下方排列。两列白底卡片、紧凑信息区、12px 卡片间距，首屏与底部导航留出间隔。 |
| 选购页 | 顶部品牌文字、购物袋入口与数量角标避让微信胶囊；三分类为蛋糕、小蛋糕、面包，默认蛋糕。分类采用黑色滑块与文字颜色过渡；当前页面不展示搜索输入框。复用首页商品卡，切分类保留旧列表至新结果就绪，失败后清除旧分类结果，保留分页 / 重试入口。 |
| 底部导航 | 改为自定义黑色圆角悬浮导航，含首页、选购、订单、我的四项及 SVG 图标。选中项高亮，页面淡入 / 淡出；快速连续点击只保留最新目标，切换失败恢复状态，保留原生 Tab 滚动恢复。订单与我的也接入过渡容器。 |
| 商品详情 | 延续大主图、分类 / 名称 / 价格 / 简介与三列说明的结构；心形收藏位于名称行右侧，黑色线性 / 实心图标配合缩放与透明度动画。真实本机保存确认后更新收藏状态。缺图占位保留主图比例。 |
| 规格弹层 | 增加入场 / 退场和遮罩渐变；按实测内容高度展开，最高为视口的 85%，标题与底部金额 / 加购按钮固定，中间可滚动。标题区域支持下拉关闭，距离或速度不足时回弹；弹层打开时锁定背景，关闭后恢复原滚动位置，加购期间阻止关闭。 |
| 购物袋 | 改为商品图与右侧名称 / 单价 / 规格 / 留言的信息行；图片 112×128px、12px 圆角，提供缺图占位和详情入口。数量使用浅灰胶囊、专用加减 SVG，删除采用垃圾桶图标；当前界面不显示原逐行 / 全选勾选控件。底部展示商品金额、待核验配送费、合计与「去结算」，通过实测底栏高度补足正文留白。 |
| 字体与共用按钮 | 新增 UI 字体规范和共享 `action-capsule.wxss`；详情「选择规格」及购物袋「去结算」共用全宽黑色主按钮与底部安全区样式。保持暖白 `#FAFAF8`、黑色主文字和中性灰辅助文字。 |

首页与选购当前均使用 `product-card` 的 `typography="home"`：名称 **14px / 600**、描述 **11px / 400**、价格 **15px / 600**。详情名称 **28px / 700**，购物袋标题 **32px / 700**；共享主按钮 **58px 高、32px 圆角、20px / 500**。规格弹层「加入购物袋」仍为 **15px / 500**，未声称所有按钮或所有页面已统一。

具体字体职责、当前实际值及后续建议见 [UI-TYPOGRAPHY.md](docs/UI-TYPOGRAPHY.md)；执行约定见 [AGENTS.md](AGENTS.md)。其中历史迁移范围以本 README 和当前代码为准，后续只调整用户指定页面。视觉验收由用户自行编译后真机确认，本次扫描及自动化检查不替代该验收。

## 工程结构

```text
miniprogram/
  pages/             四个主包 Tab：home、shop、orders、account
  custom-tab-bar/    自定义底部导航
  features/          九个业务分包页面：详情、规格、购物袋、核对、地址、收藏等
  components/        商品卡片、页头、数量角标、空状态等
  styles/            字体 / 色彩及共享黑色主按钮
  utils/             安全区、导航过渡、规格弹层等
  assets/            Hero 场景照片与 SVG 图标
  legacy/            七个旧演示分包页面，默认关闭
cloudfunctions/      最小云入口与未部署的领域模型
tests/               本地回归测试
docs/                开发计划、阶段记录、字体规范与历史 QA 截图
```
