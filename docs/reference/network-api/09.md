## C02 公开目录读取约束

公开目录纯模型、字段投影和示例Shop见 [CATALOG-READ.md](../../archive/stages/phase-3.md#catalog-read)。ProductCard必须有身份/规格组合/价格合法的ON_SALE SKU和精确登记的PUBLISHED云封面，minPriceCents仅取有效在售SKU；图网络加载失败为前端兜底。C01草稿不参与公开读。浏览不依赖库存配置，数量上下限及提前量允许明确为null；格式错误、半缺失数量范围、未知价格仍拒绝。购买继续使用resolveSku的完整经营配置校验，客户端只读目录始终canPurchase=false/canConfigure=false。

云封面默认仅REAL_PHOTO。development显式启用allowReferenceImages时，可读取已登记且catalogApproved=true的DESIGN_PREVIEW，投影保留真实来源，不返回批准元数据；test/production不能启用该例外。参考配图的商品描述如实说明来源，原开发fixture不因经营采用而改写历史标签。

CATALOG公开排序为sortOrder ASC / _id ASC；模型将当前公开分类/商品排序内容摘要加入可信query绑定，公开内容改变后旧cursor拒绝，客户端刷新第一页。纯模型的相同实例持隔离快照；云adapter在一次只读SDK事务内按_id ASC分批读取categories/products/skus/media_assets，并从有界快照生成投影和游标。这不提供订单的谓词或写保护。

服务端读取过滤为categories.published=true、products/skus.storeId=绑定目录且status=ON_SALE、media_assets.status=PUBLISHED且sourceKind=REAL_PHOTO；仅启用开发参考图时增加同索引的DESIGN_PREVIEW扫描，再由投影校验逐张批准。复合查询索引依次为published/_id、storeId/status/_id、status/sourceKind/_id。批次最多100条，分类/商品/SKU/素材上限为3/100/500/200（两种素材扫描合计），总JSON载荷上限2MiB；多读一条检测超限并拒绝，不截断后宣称完整目录。SDK明确事务冲突最多重试2次；不写业务、保护或修订文档。扩容须另行调整读取策略并验证，不将当前有界扫描当作无限目录的索引seek。

catalog只接受categories.list/products.list/product.get三个读取action，核对本次原生身份、AppID和环境；HMAC游标密钥仅在服务端配置。客户端PUBLIC_CATALOG响应不回落示例数据，空目录保持空态；缺失商品保持不可用，目录浏览不开放本机草稿加购或收藏。开发示例只在development/shell使用，development-preview.*不是HMAC服务端token。当前部署、本机开关与验收状态只查[CURRENT-STATUS](../../CURRENT-STATUS.md)。
