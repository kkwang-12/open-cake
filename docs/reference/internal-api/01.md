## 已实现的最小云接口

| 云函数 / action | 输入 | 输出与限制 |
|---|---|---|
| user / me | `{ action: 'me', payload: {} }` | development 云端工具已验证；核验本次平台身份，首次事务创建 users，复读不覆盖既有用户；返回可信摘要与 customer，禁用或损坏记录拒绝 |
| store / health | `{ action: 'health', payload: {} }` | development 云端工具已验证；本次平台身份鉴权后返回连通信息；门店业务配置尚未接入 |
| catalog / categories.list | `{ action: 'categories.list', payload: {} }` | `{apiVersion, items: CategorySummary[]}`；仅公开分类 |
| catalog / products.list | `{ action: 'products.list', payload: {storeId, categoryCode?, search?, pageSize?, cursor?} }` | `{apiVersion, items: ProductCard[], nextCursor, hasMore}`；storeId须匹配服务端目录绑定 |
| catalog / product.get | `{ action: 'product.get', payload: {productId} }` | `{apiVersion, ...ProductDetail}`；未知、跨门店、草稿或不可展示商品统一PRODUCT_UNAVAILABLE |

响应使用 `{ ok: true, requestId, data }` 或 `{ ok: false, requestId, error: { code, message } }`。身份只取平台上下文，不读取 event.openid / role。开发、测试、生产环境显式隔离。具体实现见阶段一记录。

目录输入按上述字段白名单校验，不能传入用户或角色字段。目录读取限于原生PLATFORM身份，函数拒绝匿名调用，集合客户端读写全部拒绝；云函数仅执行服务端读取。公开投影、素材来源、分页及读取预算见[目录读取约束](../network-api/09.md)。客户端目录开关关闭时返回CLOUD_NOT_CONFIGURED，服务端绑定/密钥/读取预算异常返回CONFIGURATION_REQUIRED；目录浏览不授予加购、收藏、报价、订单或支付能力。部署及验收结论只查[当前状态](../../CURRENT-STATUS.md)。

2026-10-08：SDK 4.0.2 在复用实例上可能保留上一条微信身份，两个入口现将 SDK 元组与 SCF **本次调用第二参数**的身份/namespace 一致性校验；管理端缺当前微信身份时 AUTH_REQUIRED。user.me 并非纯零写读取：仅首次可信身份可创建默认顾客，不返回 Profile、不接受角色提升，不表示隐私同意或电话认证。存储故障返回 INTERNAL_ERROR，禁用/损坏用户返回 AUTH_REQUIRED。真机仍 NOT_RUN，详情见 [阶段二实际补验收](../../archive/stages/phase-2.md#phase-2-cloud-revalidation-2026-10-08)。
