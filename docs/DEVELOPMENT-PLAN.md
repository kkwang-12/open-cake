### 每个 Task 的共同完成标准

1. 完成表中明确交付物，并通过列出的正向、异常或边界验收；不能仅以页面出现判定完成。
2. 核对所属阶段的接口、数据流与权限；交易金额 / 权限 / 状态 / 资源判断由云端执行。
3. JS / JSON / WXML 静态检查通过；交易、权限、并发与资金变更有针对性回归证据，普通低影响文档 / 样式变更不机械新增测试。
4. 涉及页面提供开发者工具截图；涉及微信能力提供真机记录；涉及云环境提供环境名、函数版本和脱敏请求 / 结果。
5. 更新 Task 状态、变更文件与证据链接；外部条件不足时标记“待外部条件”，不能标完成。
6. 数据模型或接口变化同步更新 `DATA_MODEL.md` / `API_CONTRACT.md`；在阶段二创建这些实际文件，当前不是空文件占位。
