## 1. 加入购物袋成功反馈动效

记录名称：**加入购物袋成功反馈动效（粒子爆散 + 弹性回弹 + 触觉反馈）**。

组成：按钮按压、Bottom Sheet Dismiss（规格弹层收起）、Slide Up & Fade In（成功卡片上浮淡入）、Spring Pop（商品缩略图回弹）、Particle Burst（细粒子爆散）、Haptic Feedback（短震动）。这是项目内的组合名称，不是微信提供的单个动画接口。

适用范围：商品详情页的「加入购物袋」及底部「已加入购物袋」成功卡片。

确认状态：用户此前已确认动画和震动没有问题，并在本次确认当前 UI 方案完整确定。成功卡片贴底样式以当前源码为准；本次文档与素材整理不代表额外进行过真机验收。

代码来源：

- `miniprogram/features/product/product.js`：成功校验及弹层收起衔接。
- `miniprogram/features/product/product.wxml`：成功卡片、缩略图与独立粒子浮层。
- `miniprogram/features/product/product.wxss`：动画关键帧、曲线及贴底样式。
- `miniprogram/features/product/success-motion.js`：时序、中心测量、粒子生成、震动及清理。
- `miniprogram/utils/bottom-sheet.js`：收起结束回调。

### 1.1 时序与成功条件

按钮按压与购物袋保存并行，不为动画延迟保存。只有购物袋服务返回并通过成功校验，且按压反馈已经完成，才开始收起弹层。保存失败或用户取消商品配置确认时，不出现成功卡片、粒子或成功震动。

| 阶段 | 当前实际值 | 衔接方式 |
|---|---|---|
| 按钮按压 | 180ms | 点击后开始，与保存并行 |
| 规格弹层收起 | 280ms | 等待成功校验及按压完成 |
| 成功卡片上浮淡入 | 320ms | 弹层收起、卸载并恢复滚动后挂载 |
| 缩略图入场 | 延迟 100ms，持续 220ms | 相对于卡片挂载，结束于约 320ms |
| 缩略图回弹与粒子爆散 | 卡片挂载约 320ms 后开始 | 测量缩略图实际中心，再同步更新回弹状态和粒子 |
| 成功短震动 | 一次 `medium` | 回弹和粒子状态更新完成的回调中调用 |
| 粒子节点清理 | 爆散状态更新完成后 560ms | 不移除已完成的缩略图回弹 class，避免重播入场 |

时间值是代码时长；中心测量、视图更新及设备调度会产生少量额外时间。购物袋保存耗时不固定，不将整段动画标为固定总时长。以卡片挂载为起点，粒子最晚约在 860ms 结束，节点约在 880ms 清理，另加中心测量及视图更新耗时。

### 1.2 按钮按压与规格弹层

| 参数 | 当前实际值 |
|---|---|
| 按钮缩放 | 0%：`1`；45%：`0.96`；100%：`1` |
| 按钮时长／曲线 | `180ms ease-in-out`，`animation-fill-mode: both` |
| 按压期间外观 | opacity 为 `1`；关闭原生 hover 样式；按压时不显示 loading 图标 |
| 弹层位移 | 收起目标为 `translateY(100%)`，平稳打开时起点为 `0px` |
| 弹层与遮罩时长／曲线 | `280ms cubic-bezier(0.22, 1, 0.36, 1)` |
| 遮罩透明度 | 正常打开状态 `0.48` → `0` |
| 完成处理 | 280ms 后卸载弹层、恢复原滚动位置，随后显示成功卡片 |

上述 280ms 是加购成功专用参数。普通关闭弹层仍使用共享默认的 `200ms ease-in`，不将成功参数误记为所有关闭操作的实际值。

### 1.5 发射方向、范围与屏幕边界

- 发射原点：卡片落位后测量 `.success-thumb-stage`，使用 `left + width / 2`、`top + height / 2`，即实际缩略图中心。
- 发射方向：将整周 `360°` 等分为 56 个扇区，每个扇区随机取一个角度；保证四个方向都有粒子，不固定向上喷射。
- 距离分层：42 颗的预设半径随机为 `28–58px`，14 颗的预设半径随机为 `64–88px`。这些是边界限制前的目标距离，不是所有设备都能完整达到的实际半径。
- 起点错开：沿各自方向偏移随机 `2–6px`，且不超过实际发射距离的 `15%`，避免全部粒子挤成中心色块。
- 边界预留：粒子半宽加 `3px`；向下额外预留本颗粒子的重力位移。
- 边缘处理：按屏幕可用空间缩短整条发射轨迹，保持角度。不得恢复旧版“向左乘 0.28、向下乘 0.10”的轴向压缩，否则会再次显得偏上。
- 粒子层：独立 fixed 浮层，`inset: 0`、`z-index: 40`、`pointer-events: none`；仅由视口裁切，不由卡片或缩略图内部裁切。浮层覆盖视口只是为了绘制和定位，实际运动保持局部范围，不生成满屏烟花。

正常路径使用真实测量。测量不可用时，视口默认 `375×640px`；中心备用计算为 `x = 63 - 屏宽 × 0.02`、`y = 屏高 - 底部安全区 - 41`，与当前卡片布局匹配。修改卡片尺寸或位置时需同步核对该备用值。

### 1.6 减速、重力、旋转与消散

每颗粒子的最终水平发射位移记为 `X`，垂直发射位移记为 `Y`；屏幕坐标向下为正。附加重力位移 `G` 随机为 `8–14px`，这是关键帧模拟的位移，不是物理引擎的加速度。

| 生命周期关键帧 | 水平位置 | 垂直位置 |
|---|---|---|
| 0% | 起点错开值 | 起点错开值 |
| 20% | `0.76X` | `0.76Y + 0.04G` |
| 60% | `0.98X` | `0.98Y + 0.36G` |
| 100% | `X` | `Y + G` |

前 20% 约为 `90–104ms`，快速释放大部分位移；之后减速并轻微下落。水平每段使用 `ease-out`；垂直第一段使用 `ease-out`，后续段使用 `linear`。

| 生命周期关键帧 | 缩放 | 透明度 |
|---|---|---|
| 0% | `0.65` | `0` |
| 7% | 在关键帧间插值 | `0.92` |
| 20% | `1` | `0.92` |
| 60% | 在关键帧间插值 | `0.55` |
| 100% | `0` | `0` |

初始角度随机为 `-90°–90°`，保持至生命周期 20%；其后向顺时针或逆时针旋转额外 `35°–110°`，方向按粒子交替。缩放、透明度和旋转在对应关键帧间使用 `linear`，避免大幅翻滚造成粗糙庆典感。

### 1.7 触觉反馈与清理

- 使用 `wx.vibrateShort({ type: 'medium', fail() {} })`；每次成功爆散调用一次，不在按钮按下时额外震动。
- 不等待震动完成；接口不存在、调用失败或抛错时，正常播放视觉动画，不弹错误提示、不重复补震。
- 代码仅指定 `medium` 强度，未自定义震动时长、波形或连续次数；实际震感由设备与微信决定。
- 页面隐藏、卸载、重载或重新打开规格时，清除按压、爆散启动和粒子清理计时器，移除粒子并失效旧回调，防止离开页面后补播动画或补震。
- 保存中及成功收起衔接期间阻止重复加购／重新打开规格；业务成功校验、错误提示和操作幂等规则保持原实现。

## 4. 底部导航与页面内容切换

当前导航胶囊固定，点击立即更新高亮并调度切换，重复点击当前栏目不重播。以下按脚本与实际生效样式记录，不把之前讨论的淡入目标时长写成已实现参数。

当前实现来源：`miniprogram/utils/tab-transition.js`、`miniprogram/custom-tab-bar/index.{js,wxml,wxss}`、`miniprogram/styles/shell.wxss` 及四个主页面。

- `wx.switchTab` 立即调度，不等待退出动画。只串行执行原生导航操作，期间保留最后一次目标，避免排队播放多个动画。当前栏目重复点击不会发起切换。
- 导航高亮立即更新；当前 CSS 没有 120–150ms 的图标或文字过渡，所以实际为直接选中反馈，不能记为已实现该时长。
- 脚本对新栏目设 `tab-entering` 并在 160ms 后移除。共享样式仍声明 `opacity 220ms ease-out, transform 220ms ease-out`，且 opacity 的起止静态值均为 1；因此不能据 class 存在宣称已稳定实现 160ms 淡入。旧 `tab-prepared`、`tab-leaving` 样式没有由当前切换流程启用，不作为最终方案复用。
- 页面隐藏时清除计时器与动画 class，保留缓存内容可见，使详情页原生进出场背景稳定。普通栏目切换不主动重置滚动或分类；显式从 Hero 指定分类进入选购时，按原业务逻辑切到目标分类并滚到顶部。

本次仅维护文档与素材引用，不修改上述运行时差异。不要把未启用的 8px 位移样式视为当前页面切换效果；未来动画调整须经用户明确请求，先修改真实触发代码，再同步本节。

## 6. 规格弹层与收藏反馈

以下为已核对的当前实现；保留现有方案，不表示本次重新设计或逐项重新完成真机验收。

### 6.1 规格弹层

来源：`miniprogram/utils/bottom-sheet.js`、商品详情页弹层结构与样式。

| 操作 | 当前实际值 |
|---|---|
| 打开 | 从 `translateY(100%)` 到 `0px`，`240ms ease-out`；首次挂载、布局测量后等待 32ms 启动 |
| 遮罩 | 同步从 0 到 .48；时长与弹层一致 |
| 普通关闭 | 位移到 100%、遮罩到 0，`200ms ease-in`；结束后卸载并恢复原滚动位置 |
| 拖动 | 单指向下，位移至少 5px 且纵向占优后跟手；时长为 0，遮罩随位移衰减 |
| 松手关闭 | 距离超过实际弹层高的 25%，或末次采样小于 100ms、向下速度超过 .6px/ms 且距离超过 32px |
| 取消／回位 | `180ms ease-out` 回到 0px、遮罩 .48；多指或取消不强制关闭 |
| 加购成功关闭 | 单独使用第 1 节的 280ms 自定义曲线，不替换普通关闭参数 |

测量和回调以 token 失效保护；加购进行中不允许重复打开或手势关闭。页面隐藏及卸载清除计时器，不在返回后补播。

### 6.2 收藏

来源：`miniprogram/features/product/product.wxss` 及 `product.js`。

- 空心／实心图标重叠，通过 opacity 切换；基础过渡 `150ms ease-out`，选中态使用 280ms。
- 收藏回弹为 `280ms ease-out`：scale 1 → .9（22%）→ 1.15（58%）→ 1。
- `heart-pop-a`、`heart-pop-b` 使用同一组关键帧，用于后续触发重新播放；页面隐藏清除动画状态。

## 7. 我的页面欢迎语：短语依次显现

来源：`miniprogram/pages/account/account.{js,wxml,wxss}`。2026-10-06 按用户授权实现，视觉待真机确认。

欢迎语按中文语义分为「你好，」「欢迎来到」「LUNE」三段，保持完整文案，不逐字打字。每段始终占据正常文档流位置；使用 inline-block 让短语整体显现并自然换行，不随显现插入文字或改变布局高度。

| 参数 | 当前实际值 |
|---|---|
| 第一段「你好，」 | 延迟 0ms，持续 240ms |

## 8. 购物袋 Full Swipe to Delete 与垃圾桶按钮删除（已确认）

手势流程为“跟手 → 达到 30% → 松手 → 200ms 滑出 → 200ms 位移补位 → 保存并更新”；操作行垃圾桶点击直接进入相同删除动画。两种入口共用原删除业务方法，底层手势删除区不响应点击、不展示文字，两种删除均不弹二次确认。视觉上保留商品自然上移的效果，补位主要通过 transform 完成，减少商品行逐帧布局；仅尾部空白补偿节点的高度随滚动范围收缩。完成后从现有购物袋持久化数据中移除对应 lineId。保存失败恢复实际存储中的商品并沿用错误刷新及 revision 冲突提示。最后一件商品完成动画及保存后复用原空购物袋组件，移除结算栏。

busy/loading 阻止新手势与重复操作，避免连续删除和数量修改冲突。页面隐藏、卸载或重新读取时复位手势、取消动画计时器并失效迟到的测量回调；动画完成前离开页面不提交删除。无法测量行高时沿用删除服务，不阻塞业务。相关验证：`tests/bag-swipe.test.js`、`tests/bag-page.test.js`。手势冲突、阈值回撤、快速松手、取消、阶段时长、连续删除、数量及金额、失败恢复均有自动测试。
