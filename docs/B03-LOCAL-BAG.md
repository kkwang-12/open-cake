# B03 本机购物袋交互验收

日期：2026-10-04。B03 已完成本机实现和微信模拟器验证，正式云同步及云端数量 / 金额权威验收待环境就绪。

## 实现

- Bag 增加逐行数量加减、逐行勾选、全选、移除、总件数、已选件数及已选小计；数量最低为 1，需要删除时使用移除。已有 minus / plus / check SVG 直接接入，黑色圆底由样式实现，实际模拟器显示正常。
- 固定底部小计操作区使用底部安全区，正文预留可滚动空间。非 Tab 购物袋仍无 Tab 栏。结算按钮保持禁用，状态文案“待核验”；本机计算不是正式报价。
- Home 和 Shop 的购物袋角标复用 bag-count 组件；在页面重新显示时读取同一个 local-bag 服务。显示总件数，超过 99 显示 99+，读取失败隐藏角标，避免冒充准确计数。已验收 Home 摄影及主要排版保留。
- local-bag 增加 select、updateQuantity 与摘要。数量修改复核当前规格 ID、版本、价格及已配置的数量范围；发生变化拒绝修改并提示重新查看商品，不静默改价。未知数量上限继续保持未知，本机草稿操作不代表正式经营许可。
- 所有操作写入真实本机存储并读回后才更新成功界面。操作期间禁止重复点击；失败显示固定文案并重新读取实际记录；隐藏页面不呈现迟到数量响应。
- version=1 仍是存储结构版本，新增 revision 才是本机变更计数；旧数据缺 revision 按 0、缺 selected 按 true 读取，单纯读不回写。数量异步等待期间再次操作 / 删除会触发 revision 冲突，不能覆盖新勾选或复活已删除行。
- 存储 key、lineId、商品 / SKU / 留言与已有两行数据保留，合并原行时保留勾选状态。整数分、件数及摘要防安全整数溢出。没有云账户隔离、跨设备同步、库存预留或正式 Checkout。
