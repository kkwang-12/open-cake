# 支付与退款真实验收要求

此处只维护证据要求，不重复维护结果；当前状态查[CURRENT-STATUS](CURRENT-STATUS.md)，经营/平台资料查[EXTERNAL-DEPENDENCIES](EXTERNAL-DEPENDENCIES.md)，交易政策查[TRANSACTION-RULES](TRANSACTION-RULES.md)。

| 事项 | 证据要求 |
|---|---|
| E01 隔离云环境 | 开发 / 测试 / 生产 ID 与 AppID 权限、可信运行时 / SDK / 数据库事务 |
| E03 商户关联与唯一方案 | 控制台确认 AppID / 商户绑定，选定平台集成或直接 API 一个方案 |
| 实际接口能力 | 所选账号、运行时及 SDK 可下单 / 查单 / 关单 / 退款 / 查退款；对应版本与调用证据 |
| 凭证保管与轮换 | 云端受控引用、现行版本 / 撤销，客户端及日志无密钥 |
| 通知信任边界 | 平台验签后的业务转发认证或服务端原始验签解密；伪造来源与错业务字段拒绝 |
| 环境隔离 | 配置 / 实例 / 回调 / 账本不跨环境，生产无模拟入口 |
| E14 受控实付安排 | 负责人、授权来源、窗口、金额 / 次数上限、退款与异常处理及持久预算 |
| P02 本人预支付与恢复 | 唯一未决意图、商户范围唯一编号、请求未知先查单、真实短期唤起参数及期限 |
| P03 入账及资源确认 | 来源真实性、总金额 / 付款者 / 单号 / 时间、通知 / 商户全局交易双去重、预算 / 订单 / HELD / 日志同事务，失败重试及异常资金持久化 |
| P04 查单 / 关闭 / 迟到款 | 实际认证查询补通知、关闭未知 / 已支付 / 并发、可信 CLOSED 后取消、迟到款全额意图 / 预算 / 资源及告警 |
| P05 支付会话 / 结果恢复 | 真实唤起、未知不重复付款、持久请求恢复及已付成功页 |
| P06 退款执行 / 恢复 | 商家审批、原号重试、平台可信结果、额度 / 历史详情及真实退款 |
| P07 补偿 / 对账 / 告警 | 隔离环境定时恢复、完整平台账单、差异处置与告警送达 |
| 真实资金闭环 | 允许的隔离环境一笔受控实付及退款，订单 / 账本 / 平台金额核对 |
| 恢复及竞争 | 丢通知 / 丢响应、查单、关单并发、迟到款、退款重试与告警 |

受控实付前必须有明确范围、主体、环境、预算和异常处置安排；不得把夹具或历史限时授权当成本轮授权。按[阶段七验收定义](reference/plan/phase-7.md)记录真实资金、通知、查询/关单、退款、并发/恢复及运维证据。

[原支付核查与过程结果](archive/stages/phase-7.md#payment-cloud-acceptance)保留为历史，不能把当时的环境/接口状态当成现在。
