## 1. 字体与风格

- 字体沿用 `styles/tokens.wxss`：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`。使用系统无衬线字体，不额外引入字体文件；实际字形由设备系统决定。
- 正文默认字重 400；按钮重置后继承字体，局部样式覆盖字号与字重。
- 主要文字 `#111111`，数量数字 `#000000`；正文灰色 `#666666`，商品规格/留言灰色 `#777777`，次要说明 `#888888`；黑色按钮白字 `#FFFFFF`。
- 页面背景当前实际为 `#FAFAF8`，表面色为 `#FFFFFF`。这是现有代码值，不将“白色风格”误记为所有背景均为纯白。
- 层级通过字号、字重与灰阶表达。标题和重要金额粗，商品名称适度粗，规格与说明使用普通字重；不把所有文字统一加粗。
- 字号优先使用逻辑 `px`，不按截图物理像素实现。布局可使用 `vw`/`rpx`，保持现有手机适配。`rpx = 屏幕逻辑宽度 / 750`，仅在 375px 宽屏幕上 2rpx 约等于 1px。

## 6. 所有商品卡片的统一设计规范（2026-10-05，用户已确认）

以下数值为用户已确认方案及共享卡片的当前实际值，同时作为后续商品卡片的目标规范。代码来源：`miniprogram/components/product-card/product-card.wxml`、`miniprogram/components/product-card/product-card.wxss`，以及首页、选购和收藏页的商品网格。

### 6.1 结构、比例与背景

| 项目 | 统一规范 |
|---|---|
| 整体结构 | 一个完整卡片容器，上方图片区、下方独立信息区；名称、描述、价格依次纵向排列 |
| 卡片宽度 | 填满网格列宽；两列等宽，不通过整体缩放卡片改变字号 |
| 卡片外观 | 白色 `#FFFFFF`，圆角 10px，溢出裁切；无描边、无阴影，外部 margin/padding 为 0 |
| 图片区 | 宽度为卡片宽度的 100%，高度为宽度的 68%，块级显示，无图片下方基线空隙；实际图片与失败占位共用同一尺寸 |
| 图片裁切 | `aspectFill`，保持图片比例并裁切填满；图片与信息区直接衔接，无额外分隔空白 |
| 图片圆角 | 图片自身圆角为 0，由外层卡片裁切形成上方圆角；图片底边不单独做圆角 |
| 图片占位 | 背景 `#EFEDE8`；文字 12px/400、`#666666`、行高 1.5，水平及垂直居中 |
| 信息区 | 白底，内边距上 6px、左右各 12px、下 8px；三行文字共用左对齐基线 |

图片容器采用 `height: 0; padding-top: 68%`，图片或占位绝对定位填满该容器，按实际卡片宽度计算，不依赖视口公式。页面左右各 16px、列间距 12px 的两列网格中，图片高度为 `(视口宽度 - 44px) / 2 × 68%`。三行内容均为单行时，信息区总高度约 75px；卡片总高度随图片自然变化，不设置固定总高度。当前图片使用 `aspectFill` 等比居中裁切，不拉伸；蛋糕主体及顶部装饰的最终裁切由补图后真机检查。
